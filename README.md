# Мягко° — спокойный таск-трекер для команд

Лендинг продукта «Мягко°» — таск-трекера без давления, красных уведомлений и тревожных метрик.

## ✨ Что внутри

- 🌗 Светлая и тёмная темы с сохранением в localStorage
- ♿ Доступность: клавиатурная навигация, ARIA, `prefers-reduced-motion`
- 📱 Полная адаптивность (mobile-first)
- ⚡ Чистый HTML/CSS/JS без зависимостей и сборки
- 🔍 SEO: Open Graph, JSON-LD, семантическая разметка
- 🌬 Плавные анимации на CSS и Web Animations API
